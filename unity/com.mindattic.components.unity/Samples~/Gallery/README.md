# Gallery

Open `Gallery.unity` and press Play. Everything is built from code in `GalleryDemo.cs`:

- The toolbar's theme button switches between the dark and light themes; every component restyles live.
- Multiplayer: Host (opens a lobby with a join code, Copy, a roster with colour swatches, tags and kick buttons, a Ready switch, Leave/Start), Join by IP and Join by code (a busy dialog with Cancel, then a "Couldn't connect" alert).
- Buttons and tags, Inputs (textbox, select, ranges, toggles), Progress (bars and a spinner on unscaled time), Dialogs and toasts.
- Esc, gamepad B or Start opens the pause menu; back from its root closes it.
- The Reduce motion switch makes every transition instant.

Arrows/WASD, a gamepad's stick or d-pad, Enter/A and Esc/B drive all of it.
